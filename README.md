# japon

Веб-приложение для изучения японского языка: тренировка хираганы, катаканы и фраз. Прогресс сохраняется между сессиями.

## Возможности

- **Хирагана** — интерактивная тренировка чтения и записи слогов базового и огласованных рядов (dakuten/handakuten).
- **Катакана** — аналогичные упражнения для катаканы.
- **Фразы** — изучение и повторение типовых японских фраз по категориям.
- **Прогресс** — статистика по каждому режиму сохраняется и сбрасывается отдельно; порядок вопросов случайный.
- **Веб-интерфейс** — одностраничное приложение (HTML/CSS/JS), общение с сервером идёт по WebSocket в реальном времени.

## Технологии

- Go 1.25 (`github.com/gorilla/websocket`) — сервер и логика приложения.
- Статический фронтенд — `internal/web/static` (index.html, app.js, style.css).

## Структура проекта

```
cmd/japan          — точка входа (запуск веб-сервера)
internal/app       — интерактивные потоки обучения (хирагана, катакана, фразы, прогресс)
internal/web       — HTTP/WebSocket сервер, сессии, протокол
internal/data      — статические учебные данные (каны, фразы)
internal/kbd       — абстракция ввода с клавиатуры
internal/ui        — консольное меню
```

## Запуск

```bash
go build -o japan ./cmd/japan
./japan -addr :8095
```

Затем откройте в браузере http://localhost:8095.

## Тесты

```bash
go test ./...
```

## Деплой

На сервере достаточно выполнить `./deploy.sh`: скрипт делает `git pull`, собирает новый бинарник и перезапускает systemd-сервис `japan` (логи: `journalctl -u japan`).
